## ✨ Nueva Versión Simplificada

He creado una versión **MUCHO MÁS SIMPLE** del proyecto usando Android nativo en lugar de React Native/Expo.

## 🚀 3 Pasos Para Tener Tu APK

### Paso 1: Subir a GitHub (2 minutos)

```bash
git add .
git commit -m "Proyecto Android nativo - Ayni MINEDU"
git push
```

### Paso 2: Ejecutar GitHub Actions (1 minuto)

1. Ve a tu repositorio: https://github.com/TU_USUARIO/ayni-minedu
2. Clic en pestaña "Actions"
3. Clic en "Build Android APK" (izquierda)
4. Clic en "Run workflow" (derecha)
5. Clic en el botón verde "Run workflow"

### Paso 3: Descargar APK (5-8 minutos de espera)

1. Espera a que termine (verás ✅ verde)
2. Scroll abajo en la misma página
3. Sección "Artifacts"
4. Clic en "ayni-minedu-apk"
5. Se descargará un ZIP
6. Descomprime el ZIP
7. Instala `app-release-unsigned.apk`
