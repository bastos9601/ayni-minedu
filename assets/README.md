# Assets - Iconos y Splash Screen

Esta carpeta debe contener los siguientes archivos:

## icon.png
- **Tamaño**: 1024x1024 píxeles
- **Formato**: PNG con transparencia (fondo transparente)
- **Uso**: Icono de la aplicación en el teléfono

## splash.png
- **Tamaño**: 1284x2778 píxeles
- **Formato**: PNG
- **Uso**: Pantalla de carga al abrir la aplicación

## Cómo crear los iconos

### Opción 1: Usar una herramienta de diseño
- Canva (https://www.canva.com) - Gratuito
- Figma (https://www.figma.com) - Gratuito
- Adobe Illustrator - De pago

### Opción 2: Usar generadores online
- https://easyappicon.com/
- https://appicon.co/
- https://makeappicon.com/

### Opción 3: Crear un icono simple temporal

Mientras consigues el diseño final, puedes usar iconos temporales:

1. **Para icon.png**: Crea una imagen cuadrada de 1024x1024 con:
   - Fondo de color (ejemplo: #0066cc azul)
   - Texto "AYNI" en el centro
   - Guárdala como "icon.png"

2. **Para splash.png**: Crea una imagen de 1284x2778 con:
   - Fondo blanco o de color corporativo
   - Logo o texto "Ayni MINEDU" en el centro
   - Guárdala como "splash.png"

## Importante

⚠️ **Sin estos archivos, el proyecto no compilará correctamente.**

Si no tienes los diseños listos, puedes:
1. Buscar "ayni minedu logo" en Google
2. Descargar el logo oficial
3. Redimensionarlo a los tamaños requeridos
4. O usar iconos placeholder temporales
